How it works

From request to reconciled revenue

An app asks for an ad

The SDK (or an exchange over OpenRTB) sends one lightweight request, with consent signals.

The auction runs in memory

Targeting, floors, brand safety and pacing are applied with no database call on the hot path.

Events are signed and tracked

Impressions, clicks, completions and installs use expiring signed links, so replays and forgeries fail.

The ledger is the truth

Events flow through Kafka into an append-only Postgres ledger. Wallets, reports and payouts are derived from it.

Integrate in an afternoon

The SDKs enforce the rules the ad server relies on, so a correct integration cannot produce invalid traffic by accident: one impression per ad, no instant clicks, and no device ID without consent.

  • JavaScript SDK for web and React Native, zero dependencies.
  • Kotlin (Android) and Swift (iOS) SDK cores with the same behaviour.
  • Full OpenAPI spec, plus an OpenRTB 2.6 bidder endpoint for exchanges.
import { MobiAd } from './mobiad-sdk.js';

const ads = new MobiAd({ appId: 'app_…', baseUrl: 'https://ads.example.com' });
const ad = await ads.requestAd({ format: 'banner', country: 'US' });

if (ad) {
  render(ad.creative);        // title, image, video…
  await ad.onShown();         // when it is actually visible
  button.onclick = async () => open(await ad.onClicked());
}

FAQ

Questions, answered plainly

Do you store user profiles?

No. Ads are contextual. A device identifier is only used, hashed with the app, the day and a server secret, to enforce frequency caps, and only when consent allows it.

How do I know billing is correct?

Every billable event is one row in an append-only ledger with a unique token hash, so replays cannot double-bill. Wallets and earnings are calculated from the ledger, and you can download itemised statements.

What stops fake clicks?

Clicks that arrive too fast, without an impression, from a flooding source, or after expiry are recorded as invalid and never billed. Apps with unusual traffic are flagged and their earnings are held for review.

Can my team use it?

Yes. Invite admins and viewers to your account. Members cannot add funds, request payouts or manage keys.

Can I automate things?

Yes. Create scoped API keys to read reports, manage campaigns, and send conversion postbacks from your server.
